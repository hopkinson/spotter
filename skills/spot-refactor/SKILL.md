# 重构检查

`spot-refactor [路径]` 检查当前工作区中的文件或目录。省略路径时，从全仓的手写源码中优先看近期反复修改、快速变长或明显偏大的文件。排除生成文件和第三方代码。行数只用来筛候选。

读取 `../../bundled-skills/spot-ponytail-review/SKILL.md` 中的精简度检查和证据标准。读候选文件、实际调用方和相关测试，确认是否混管独立职责、重复实现同一规则，或让一处行为变更必须跨多处同步。

只报告有具体维护代价、且能指出最小改法的候选。每条给出文件与行号、维护代价、应删哪段、复用哪处或按什么职责拆分，以及用哪个测试或行为场景保住结果。说明检查范围与缺口，没有值得重构的发现就如实说明。只出报告，实际重构另行发起。

## 检查收尾流转
- 有重构项时：按优先级编号标出候选。在【下一步操作】中直接提示：`回复「重构第 X 项」自动转入 spot-plan 规划最小方案`，或 `回复「暂不重构」保持原状`。
- 无重构价值时：在【下一步操作】中明确提示代码健康，无需额外改动。
