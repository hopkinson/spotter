# 配图文字版

以下为说明技能表达方式的示例，不代表真实产品实现或验证结果。

## 回答效果对比

同一请求：给删除文件操作增加一次确认，并说明改动。

### 普通回答

当前点击「删除」后，文件会立即移除。建议增加确认弹窗：点击「删除」后，先显示「确认删除？」。选择「确认删除」才移除文件；选择「取消」则保留文件。

### 使用技能：改前

```text
[删除] → 文件移除
```

### 使用技能：改后（建议）

```text
[删除] → 确认弹窗
           ├→ 确认删除 → 文件移除
           └→ 取消     → 文件保留
```

## 页面案例

同一请求：收起次要筛选条件，给我改前改后对比。

### 改前

```text
姓名 [      ]  电话 [      ]  状态 [全部 ▾]
日期 [      ]  部门 [      ]  来源 [全部 ▾]  [查询]
------------------------------------------------
案件列表
```

### 改后（建议）

```text
姓名 [      ]  [查询]  [更多筛选 ▾]
------------------------------------------------
案件列表

[更多筛选 ▾] → 电话 / 状态 / 日期 / 部门 / 来源
```

边界：只改变筛选项的展示方式，不移除字段。
